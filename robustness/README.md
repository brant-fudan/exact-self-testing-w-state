# Supplemental Data for PHYLA-D-26-02336

This package accompanies the revised manuscript **Exact Self-Testing of the Three-Qubit W State from Marginal Correlations**.

It contains the exact finite certificate used in the ideal-point proof and in the quantitative stability estimate, together with the verification script.

## Contents

- `supplementary/revised_certificate.json`: machine-readable exact certificate;
- `verification/verify_revision.py`: verification script;
- `requirements.txt`: Python dependency used by the verifier.

The mathematical role of these objects and the robustness derivation are described in the manuscript, in particular Appendix D.
